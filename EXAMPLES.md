# Usage Examples

Start a new Codex session after installing and trusting the plugin hooks. The
exact suggestion text is generated by the active model, so wording can vary.
The observable contract is the presence, position, language, and relevance of
the `Suggested next prompt:` line.

## Example 1: Suggest a useful next action

Send:

```text
Explain why focused tests are useful after changing code and recommend what to do next.
```

An illustrative response is:

```text
Focused tests give fast feedback on the behavior you changed and make failures
easier to diagnose. Once they pass, run the broader project checks before
considering the change complete.

Suggested next prompt: Run the focused tests for my changed module and explain any failures.
```

Verify that:

- exactly one line starts with `Suggested next prompt:`;
- it is the final non-empty line;
- it contains a concrete prompt the user could submit next;
- it uses the same language as the conversation.

## Example 2: Preserve exact output

Send:

```text
Reply with exactly the single word OK.
```

Expected response:

```text
OK
```

The response must not contain a `Suggested next prompt:` line because adding it
would violate the user's exact-output requirement.

## Example 3: Wait for required user input

Send:

```text
Help me connect to a server, but ask me for the server address before doing anything else.
```

An illustrative response is:

```text
What is the server address?
```

The response should not add a separate suggestion. The assistant is already
waiting for information required to continue.

## Troubleshooting

If Example 1 has no suggestion:

1. Start a new Codex session so the `SessionStart` hook runs.
2. Open `/hooks` and confirm the plugin's `SessionStart` and `Stop` handlers are
   trusted and active.
3. Run `codex plugin list --json` and confirm
   `codex-next-prompt@codex-next-prompt` is installed and enabled.
4. Make sure the prompt allows a useful next action. Exact-output requests,
   acknowledgements, refusals, and questions waiting for user data intentionally
   omit suggestions.

The plugin provides response-level guidance only. The suggestion is not inserted
into the composer and cannot be accepted with Tab or Right Arrow.
