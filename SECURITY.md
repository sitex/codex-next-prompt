# Security Policy

## Supported Versions

Only the latest published version receives security fixes. The project is in
early development; unsupported versions should be upgraded before reporting a
known issue.

## Reporting a Vulnerability

Please do not open a public issue for an undisclosed vulnerability. Report it
privately through the repository's GitHub security advisory mechanism when it
is enabled. If that mechanism is unavailable, contact the repository
maintainer through the private contact method listed on the GitHub profile.

Include the affected version or commit, reproduction steps, impact, and a
minimal proof of concept when safe to provide one. Do not include credentials,
personal data, transcripts, or other sensitive material.

The plugin is designed to be local-only. Reports involving unexpected network
access, telemetry, transcript reads, persistence, automatic continuation, or
composer mutation are especially important.
